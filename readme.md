# CRUD API – Node.js + TypeScript

A simple REST API that supports full CRUD operations for user entities. All data is stored in memory (in-memory storage). The application is written in TypeScript using only the built-in `http` module (no frameworks).

---

## Installation

```bash
git clone https://github.com/xsetiqq/CRUD-API.git
cd crud-api
npm install
npm run start:dev
npm run test
